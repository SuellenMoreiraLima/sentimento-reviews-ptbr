# Demo: sentimento de avaliações em português

Página que roda o modelo [`suellenlima/bertimbau-sentimento-reviews-ptbr`](https://huggingface.co/suellenlima/bertimbau-sentimento-reviews-ptbr) **direto no navegador**, com [Transformers.js](https://huggingface.co/docs/transformers.js) e a versão ONNX quantizada do modelo. Não há servidor: nenhum texto sai do computador de quem usa.

Código-fonte e detalhes do treino: [GitHub](https://github.com/SuellenMoreiraLima/sentimento-reviews-ptbr).
